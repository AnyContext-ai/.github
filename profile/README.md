# AnyContext
Context as a Service for your LLM-powered applications.

## What we do
AnyContext delivers context to your LLM-powered applications. We offer a fully-managed, cloud-based solution where you can connect to your custom APIs, or select a pre-made API integration.

## How we do it
We deliver your API data to your LLM-powered application through cloud-based MCP servers. MCP is a protocol for adding context to LLM clients.
